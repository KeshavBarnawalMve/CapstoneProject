# Project 15 - Automate Server Configuration with Ansible

## Objective
Automate web server installation using Ansible.

## Tools Used
- Ubuntu
- Ansible
- Apache2

## Steps Performed

1. Installed Ansible
2. Created inventory file
3. Tested connectivity using ping module
4. Created Ansible playbook
5. Installed Apache automatically
6. Verified service status
7. Accessed web server on localhost

## Result

Apache web server was successfully installed and configured using Ansible automation.
