# Project 2: Host a Static Website on Amazon S3 Using Terraform

## Goal
Publish a static website on Amazon S3 using Terraform.

## Process
1. Configure AWS credentials and initialize Terraform.
2. Write Terraform code to create an S3 bucket with a unique name.
3. Enable static website hosting and configure `index.html` as the default document.
4. Create the required bucket policy and public access settings to allow visitors to access the website.
5. Upload the website files, including `index.html`, to the S3 bucket.
6. Apply the Terraform configuration to create and configure the resources on AWS.
7. Retrieve the S3 website endpoint and open it in a browser to verify the website.
8. Push the Terraform code and website files to GitHub.

## Testing
Open the S3 website endpoint in a browser and verify that the webpage loads correctly.

## Deliverables
- GitHub repository link.
- Screenshot of the working website.
